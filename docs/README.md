# Документация на 7x7office

7x7office е самохоствана платформа за файлове и офис документи. Сървърът е `secp` (Baga), интерфейсът е Next.js. `secp/cells-5-dev/` е референтно копие на Pydio Cells и не се пуска като продукт.

Планът на фазите е в [PLAN.md](../PLAN.md). Архитектурата на модулите е в [README.md](../README.md).
